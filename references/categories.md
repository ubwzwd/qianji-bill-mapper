# 钱迹分类映射表

本表是把银行账单商户名/摘要往用户**自定义的分类体系**上靠的参考。自动推断时**只能从下面这些名称里选**，名称必须字符级完全一致，**不要自创新分类名**（否则导入后会污染账本）。拿不准就**留空**，让用户在 App 里手动归类。

> 说明：以下分类是该用户的自定义体系，不是钱迹官方默认分类。导入时若账本里没有同名分类，钱迹会按其规则处理（建议用户首次导入后核对一次分类是否符合预期）。

## 特殊类型（转账 / 还款 / 报销）

这些类型**没有分类**（分类、二级分类都留空），详见 SKILL.md 的类型判定规则：
- `转账`：本人账户间划转（提现、转入理财等），账户2 填目标账户。
- `还款`：信用卡还款（账户1 = 还款来源，账户2 = 被还的信用卡）。信用卡账单里的「还款/payment received」属于此类，**别错记成支出**。
- `报销`：垫付后收到的报销款；拿不准时当「其他」分类的普通收入即可。

## 留空原则（重要）

以下情况**一律把分类和二级分类都留空**：
- 商户名是一串看不懂的代码、缩写、收单机构编号（如 `PAYNOW`、`POS 6231****`、`财付通-****`）
- 备注里没有任何能判断用途的信息
- 能判断是支出/收入，但判断不出具体用途
- 介于两个分类之间、没把握
- **二级分类可单独留空**：能确定一级分类（如「餐饮」）但分不清早/午/晚餐时，二级留空、一级照填

留空是安全的——用户会在钱迹里手动补。**乱猜分类比留空更糟**，因为会污染账本。
